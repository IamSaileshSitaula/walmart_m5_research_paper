# M5 daily item-store cleaning - data-quality report

Pipeline v1.0.0. Generated by `python -m m5_cleaning.run_pipeline`. No forecasting model was trained and no inventory simulation was run.

> **Scope caveat.** M5 records *units sold*, not unconstrained demand, and contains no verified on-hand inventory or historical stockout labels. Recorded zeros are zero units sold, not zero demand. Any later inventory results must be labelled **simulated**.
